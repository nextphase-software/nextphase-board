# 0003 — Room sync contract

CONTRACT VERSION: 0003 sync v10 (2026-11-08)

Status: Draft for 0007-W1 v1. Replaces [sync v9](0003-sync-v9.md).
All its edit/comment/presence, immutable generation, lifecycle and 4403/4423
rules continue except the explicit timer additions in
[workshop timer v1](0007-workshop-timer-v1.md).

Current joined adds the actor-free timer snapshot and serverNowMs. Dispatch
timer_command and timer_read before the existing edit-only fallback; retain
renew/presence/comment/edit behavior, strict key sets and outer1,048,576-byte limit.
The timer contract owns exact envelopes,1,024-byte limits, separate budgets,
server stamps, expected-version ordering and post-commit broadcasts. No timer
work goes through edit receipts, waiting/dependency queues or automatic resend.

Fresh strict access replay gates socket join with its timer snapshot and every
timer read/sample/mutation/publication. If replay alone is unavailable after live
lifecycle succeeds, cached ordinary ticket/export/edit behavior remains v9's;
socket join now refuses503 service_unavailable until strict replay recovers.
Existing sockets keep ordinary policies but receive no cached successful timer
reply/publication during the outage. This is a narrow timer/socket admission gate,
not a global removal of cached ordinary operations. The older checks and amended
outage phases are explicitly enumerated in the brief.

Timer refusals have their own discriminant and never imply a refused document
edit. Connected clients use monotonic server-time samples; ignore stale version,
generation, account and connection results. One pending mutation/readback, no
offline queue/replay. A role-change4403 freshly authorizes/rejoins and retains
the tab's timer input draft if board access remains; newly admitted viewers keep
all timer controls. Confirmed access loss/sign-out/account change clears timer,
input, panel, pending work, clock and title. Never replay old controls on rejoin.
4423 document restore preserves the live timer and tab draft, obtains a current
snapshot/sample under the new generation, and never reuses an old command.
