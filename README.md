# NextPhase Board

A collaborative visual workspace for teams.

This repository is at the project scaffold stage. There is no runnable application
or supported deployment yet.

The prerequisites for [0001-W1 v2](docs/briefs/0001-W1-capture-and-reopen-a-board.md)
and its [technical contracts](docs/architecture/README.md) were accepted on
2026-10-22. They define a browser-local capture/reopen workflow and exact
dependencies. Application implementation requires a separate maintainer handoff.

## Contributing

Read [CONTRIBUTING.md](CONTRIBUTING.md), [DESIGN.md](DESIGN.md), and
[AGENTS.md](AGENTS.md). Implementation work uses versioned, self-contained
[briefs](docs/briefs/README.md). Implementation has not started.

Build, test, and local development commands will be documented alongside the first
runnable implementation. All required source and build inputs must be available
from this repository and documented public dependencies.
