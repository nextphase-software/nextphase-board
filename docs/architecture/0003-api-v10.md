# 0003 — Server API contract

CONTRACT VERSION: 0003 API v10 (2026-11-09)

Status: Draft for 0007-W2 v1. Replaces [API v9](0003-api-v9.md).
All HTTP paths, authentication, origin/ticket secrecy, one-use/capacity ordering,
lifecycle/status ordering and narrow strict socket gate remain. Existing
POST /boards/:board/join-tickets and GET /boards/:board/join?ticket=... admit the
socket; joined now also carries the recipient's voting projection from
[voting v1](0007-workshop-voting-v1.md). No voting HTTP route, roster endpoint,
directory field or URL fragment. Issued ticket never guarantees later admission.

Fresh socket strict replay failure returns503 service_unavailable without joined
state. Reads/commands/publications use live current authority and per-recipient
projection; viewers receive no ballot. Retain ordinary cached HTTP policy.
Existing operator restore body/authentication limits remain:400 bad_request for
injected voting tables/top-level/meta/row keys before fences/writes. A valid
operator restore clears workshop state; user document-history restore preserves
and reconciles it. See [persistence v10](0003-hosted-persistence-v10.md).
Hosted images remain refused. No service schema/deployment/dependency change.
