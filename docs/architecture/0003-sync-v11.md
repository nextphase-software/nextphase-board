# 0003 — Room sync contract

CONTRACT VERSION: 0003 sync v11 (2026-11-09)

Status: Draft for 0007-W2 v1. Replaces [sync v10](0003-sync-v10.md).
All edit/comment/timer/renew ordering, receipts, immutable transport generation,
4401/4403/4409/4423 and ordinary cached-operation rules remain. Apply the
[brief's version set](../briefs/0007-W2-vote-and-reveal-workshop-results.md).

[Voting v1](0007-workshop-voting-v1.md) owns exact vote_command/vote_read,
vote_result/vote_state/vote_snapshot/vote_refused keys, bounds, split versions,
strict recipient projections and refusals. Joined adds voting:Projection. Route
voting kinds before edit-only fallback, in the single Room.ordered queue. Never
share a ballot frame across accounts or route vote refusals through edit receipt/
waiting/refused-edit recovery. No offline queue, merge, automatic resend or retry.
Private mutations do not advance sessionVersion or publish to other accounts.
Same-person tabs receive their own current ballotVersion; reads at equal public
version can carry updated own state or visible target reconciliation.

Socket admission already requires strict live replay from v10; retain its503
behavior and prior outage phases. Each voting send/read/mutation independently
rechecks lifecycle/token/effective role/epoch/restoreGeneration; reconstructed
sockets cannot authorize from attachments. Presence is redacted per
[presence v2](0004-presence-v2.md) before every join/relay while running.

One pending mutation,2,000ms readback,15,000ms reads/30,000ms freshness and
separate5-attempt budgets are voting-specific. Fresh4403 viewer rejoin removes
own state/input while keeping metadata and timer rights. Confirmed terminal loss
clears protected state before late replies.4423 refreshes transport generation
while preserving/reconciling current live workshop state; never replay a command
or historical transition announcement. Document edits retain their own queues.
