# 0003 — Server API contract

CONTRACT VERSION: 0003 API v9 (2026-11-08)

Status: Draft for 0007-W1 v1. Replaces [API v8](0003-api-v8.md).
All HTTP paths/shapes/authentication/origin/ticket/lifecycle/status ordering stay,
including current-owner unavailable-board grant removal. No HTTP timer route.
POST /boards/:board/join-tickets and GET /boards/:board/join?ticket=... remain
the only timer transport admission paths; they do not grant document edit rights
to viewers. [Timer v1](0007-workshop-timer-v1.md) defines joined's timer/serverNowMs
fields and timer socket commands, reads, replies and refusals.

Socket upgrade requires successful strict current access replay before consuming
the one-time ticket/publishing joined; unavailable replay returns503
service_unavailable without joined/timer state. Retain bearer/origin/invalid-ticket
checks and generic refusals, no new actor or metadata oracle. Ordinary HTTP
ticket issuance/export policies remain inherited; an issued ticket is not proof
that a later socket admission will succeed. Restore-validation rejects injected
timer payload with400 bad_request before fence/write, under the existing operator
route's authentication and body-size checks. See [persistence v9](0003-hosted-persistence-v9.md).
No new route, list field, lifecycle result field or browser fragment is introduced.
